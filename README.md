# Paintadom

Paint. Relax. Build Your Kingdom.

A mobile-first gamified digital coloring book built as a MiniPay Mini App on Celo.

## Loop

1. **Paint** pages → earn **Sparks**
2. Tap the **hammer** → spend Sparks on building stages
3. Finish all stages in a kingdom → unlock the next kingdom level
4. Out of Sparks? Paint more or buy a Spark pack

## Stack

- Next.js 14 + TypeScript + Tailwind
- Framer Motion · Viem/Wagmi (MiniPay auto-connect only)
- Zustand (local progress)

## Run

```bash
pnpm install
pnpm --filter web dev
```

Open http://localhost:3000 — on phone use your LAN IP (same Wi‑Fi).
